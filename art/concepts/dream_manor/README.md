# 梦境洋房概念资产

`[已采用]` 本目录保存洋房 v1 的正式建模参考；`work/dream_mansion_concepts/` 中的评审原件没有被覆盖。

- `manor-floor-plan-v1.png` 决定南北轴线、四个当前房门、一扇锁闭外门和两个未来扩展模数的拓扑与门序。
- `manor-concept-board-v2.png`、两张多角度板及其单图决定英式工艺美术语言、住宅陈设、黄昏明暗和旧化程度。
- 生成透视图不决定精确尺寸。实施阶段按负责人确认将前厅扩大为 `7.6 x 6.8 m`、内廊净宽扩大为 `6.8 m`，长度 `18 m`、净高 `4.2 m`；权威数值记录在 `dream-manor-v1-manifest.json`。
- 透视图可能出现的细小门位误差不得覆盖稳定门序；Blender 源和运行时交互均以 manifest 与 Godot 标记为准。

所有采用生成图的完整提示、来源关系和哈希见本目录的两份 prompt、两份 JSON 清单及 `assets/generated/provenance.json`。
