## 正式入口

`[已实现]` F5 新游戏仍先进入四室梦境。正常路线完成最后的对白后，从 `ExitOpened` 转为 `CompletedEscape`；大头针确认刺醒后为 `CompletedPin`。两路清理梦中携带物品，不发放现实奖励、不增加关系或调查线索。已知梦境记录不伪造为现实证据。

淡出梦境，在住宅现有床边安全点淡入，播放两句简短字幕，随后可以行走、操作门灯并从正门进入村庄 v2。主角使用已有站立与行走动作，没有起床动画或现实晓雨。现实固定周六 08:00，移动不推进日期；床铺不提供结束当天。

正式暂停菜单提供保存、载入、安全点恢复、设置、返回标题和退出。没有预览重置、Legacy 手册／任务、额外跳过入口或村民委托。独立 `HomePreview.tscn`、`VillagePreview.tscn` 与 `--village-v1` 仍保留，且不访问正式存档。

## 状态与责任

- `GameState.VillageExploration` 为可选 Core 状态；新位置标识 `village.home`、`village.exterior` 不复用 `old_house`、`station_quarter`。
- 现实 X/Y/Z 为米，另存朝向弧度、镜头水平角、醒来介绍完成位、门灯布尔值。Legacy Player 二维坐标含义不变。
- `VillageExplorationService` 负责醒来边界、介绍完成、快照校验与提交；`GameSession` 负责原有原子文件保存。重入不重置已存在的现实状态。
- `VillageAreaHost` 管理两区缓存、切换、碰撞安全落点、状态导入导出，不读取 GameSession；`VillagePreviewController` 保留独立入口。`MainController.Village` 接管正式会话、字幕、存档与输入锁。
- 主门在嵌入模式是换区入口，另外四扇室内门保留开关；六组灯保留操作。门只保存上次稳定端点和可选 `DoorOpenSides` 开启方向；开合动画和受阻状态不入档。2026-09-15 旧档兼容与缓存恢复更新见[双向推门](home-access.md)。

## 存档与恢复

`[已实现]` SaveEnvelope v1、梦境内容版本 6 不变，新状态作为可选字段向后兼容。旧程序不保证能读取含新地点的存档。

| 输入存档 | 当前处理 |
| --- | --- |
| 无 DreamEscape 的 Legacy | 原路线继续 |
| 当前 v6 InProgress | 原梦境区域与进度继续 |
| 当前 v6 ExitOpened | 播完未完成收尾对白后醒来 |
| PendingWake | 恢复醒来流程 |
| 通过现有校验的 CompletedEscape／CompletedPin，未有现实状态 | 首次迁入卧室 |
| 已有现实状态，介绍未完成 | 恢复位置后重播未完成的短介绍 |
| 已有现实状态，介绍完成 | 直接恢复探索，不再进入梦境 |
| 旧版未完成梦境 | 保留既有需要重开规则 |

醒来边界、介绍完成、换区完成、门灯操作完成时保存；手动保存、返回标题及正常退出前捕获位置。探索移动本身不持续写盘，异常进程终止恢复最近检查点。转场中禁用重复操作和保存，恢复完整的上一检查点。

载入先恢复门灯，再检查角色落点的场地边界、地面高度和实体碰撞；不合法空间位置回所在区域安全点。未知区域／门灯键、非有限数字和不一致的梦境终态拒绝读取。存储失败显示提示，菜单保存可重试，返回标题／退出保存失败时不离开。

## 制作边界

本轮复用住宅 v1／村庄 v2 模型，不修改 Blend、GLB、共享建模布局或其他建筑。新增字幕只是醒来表现，未新增任务事件 catalog、NPC 或 `.dialogue` 事件，不改变梦境 13 个原事件的提交。第一章任务编排仍以[第一章细案](../design/chapter-one.md)为准。

本机角色与包含角色的画面仍只限本机非商业，禁止提交、推送、分发和游戏导出。缺失角色资源时继续 billboard 回退。
