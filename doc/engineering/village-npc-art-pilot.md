# 旧模块化 NPC 样板失败记录

`[已实现]` 2026-09-18：负责人要求完全放弃此模型。旧 Blend、贴图、四套 GLB、配方、构建脚本、`VillageNpcArtPreview.tscn`、专项探针和专用控制器已退出活动项目路径。批量删除被工具自动审批拦截后，采用可逆隔离，文件保存在被 Git 和 Godot 忽略的 `work/shen-yan-v2/retired/`。这不是可运行的备用美术版本，不得重新作为居民基底。

当前路线见[沈砚静态 v2](shen-yan-static-v2.md)及[本轮实际验收](../production/shen-yan-static-v2-validation.md)。原低模 `VillageNpcPreview.tscn` 继续作为对话、巡逻和状态隔离的功能对照，正式村庄仍为 v6。

## 失败原因

09-17 的技术管线曾生成 21 骨骼、四组动作、四个配方和三档 LOD，通过导入与运行时检查。但无受限角色审图显示，脸部、人体连接、衣物结构和外观差异都没有达到要求。满足面数、骨骼和材质数量，不能证明模型长得自然或好看；先批量生成不合格基体只会放大返工。

因此不再沿用旧几何、UV、贴图、脸、发型或骨架。旧命令和场景入口已移除，历史自动结果仅见[旧验收](../production/village-npc-art-pilot-validation.md)，不能用于当前资产。

## 保留的程序边界

`VillageNpcActor3D`、`VillageNpcArtPolicy` 和对话/巡逻边界中不含旧模型的通用代码可保留。当前目录校验只允许 `pilot` 和原低模资产目录，拒绝已退役美术和新的未批准静态候选；静态审图使用独立节点，不经过要求骨骼和 LOD 的 actor。

旧人数分配规则不是总三角面预算证明：四名 32k、四名 10k、四名 2.5k 合计 **178k**，超过原 170k 上限。以后真正接入居民时需要按资产实际成本分配，并重新做整帧、动画和目标硬件矩阵；本轮没有宣称或完成这项工作。

`[固定约束]` 女性基体、乔姨高质量美术、绑定、动作、LOD 和批量配方，均等待新的单人样板视觉通过后再安排。
