## 页面行为

- `[已实现]` 标题使用原环境背景与左侧文字菜单，保留继续条件、命名长度校验和退出确认。暂停为侧边菜单；设置分为显示、操作、辅助功能。
- `[已实现]` 探索保留紧凑区域名与靠近关注对象的提示；模态期间隐藏探索标记。取得物品和记录仍用短通知。
- `[已实现]` 解谜失败短提示注明主角姓名，加入前只回想已知材料，加入后深入帮助由主动商量提供；同一上下文的文案交替显示。题面不直接提供解法，三级求助以自然对白提出局部建议。
- `[已实现]` 对白为下方居中、最多两行的局部柔影字幕；独立姓名、继续提示和选项。背景可关闭或切高对比；工具入口收纳历史、自动和仅跳已读，保留取消和重试。详见[样板](ui-cinematic-samples.md)。
- `[已实现]` 背包使用图标网格、选中物品放大图与详情；150% 字号分物品／详情页。普通物品仍自动用于机关，大头针保留确认。
- `[已实现]` 梦中记录按区域索引，只显示已发现信息。晓雨将免费可重复的合作观察与逐级求助分开。
- `[已实现]` Legacy 手册拆为暴露征兆、人物、日程、承诺、事实、证据、线索、时间线、对白历史；事实、证据与线索保持分离。
- `[已实现]` Legacy 战斗使用局势、独立滚动历史和固定行动栏，保留撤退、失败重试和继续路径。

## 机关与输入

| 类型 | 操作 |
| --- | --- |
| 窗扣 | 点按切换位置，焦点确认或滚轮离散调整。 |
| 时钟 | 点击或拖动指针：内圈调时、外圈调分；右侧焦点控件和滚轮保留离散步进。 |
| 值日表 | 拖动纸片对齐断边，或用焦点控件循环位置；独立选择值日项。 |
| 纸带 | 拖动交换或先后选中两片交换，始终保留四片且不生成重复纸片。 |
| 合影 | 底片、孔卡、滤片独立开关与四个候选位置；三层未完成时确认禁用。 |
| 音板、声学墙、排列 | 点选条目进入槽位，槽位支持拖动/选中交换；保留数字直输、重复规则、波形和文字观察。 |
| 舞台 | 四组配重、三块影盘、正面投影与晓雨侧台观察；反馈仍由 `DreamStageRules` 推导。 |

`[已实现]` 所有谜题保留撤销、重置、返回和明确提交。机关没有资料切页或嵌套阅读模态。纸片只在有效释放时交换；Esc／B、失焦、隐藏和关闭取消拖动。时钟/值日表连续手势只增加一次撤销记录，取消恢复手势开始前的值。

`[已实现]` `project.godot` 显式绑定菜单 A 确认、B 返回、十字键与左摇杆导航，避免依赖只有键盘的默认菜单映射。键盘使用方向键、Enter、Esc；Backspace／X 撤销；Q／E 或 LB／RB 切换管理页。I／Tab／X 的原有背包开关保留。

## 状态与验证

`[固定约束]` 不改变谜题答案、物品链、剧情结果、内容版本或剧情存档字段。负责人批准的独立字幕设置新增两个兼容旧档的设置字段，见[架构](architecture.md)。`Submitted` 只在明确确认时发出；`PreviewChanged` 传递局部预览；`Closed` 通知既有合作预览复位。选择、拖动、撤销历史、页签和独白轮换均属于表现层。`ModalGate` 继续阻断世界移动与交互。
