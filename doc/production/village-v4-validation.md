## 加载、内存与预算

RTX 2080 Ti、OpenGL 3.3、相同上午环境与角色，顺序运行五组 v4／v2 启动，不并行运行图形或构建。见[五组明细](../../outputs/village-v4/loading-comparison.json)，日志 `load-v4-1..5.log` 与 `load-v2-1..5.log`。

| 指标 | v2 | v4 |
| --- | --- | --- |
| 第一组加载 | 2.524 秒 | 12.311 秒 |
| 后四组加载中位数 | 1.123 秒 | 0.678 秒 |
| 后续帧时间均值 | 16.490～16.554 ms | 16.507～16.542 ms |
| 后续帧时间 P95 | 16.771～16.798 ms | 16.771～16.807 ms |
| 后续进程工作集 | 526.8～530.9 MiB | 528.0～531.6 MiB |
| 后续引擎报告渲染显存 | 299.0 MiB | 207.8 MiB |

后续加载达到“不超过 v2 +1 秒”。定位到大贴图 Lossless 导入造成的加载成本后，仅 v4 提取图改为 S3TC VRAM 压缩及 mipmaps；暖启动模型阶段从 v2 约 534 ms 到 v4 约 75 ms。源图、分辨率和 Terrain3D 品质保留。

**首次加载仍较慢。** 操作系统缓存未清空；首次纹理／着色器处理与后续缓存不能混为一个数。最初 Lossless 单次为 16.462 秒，完整模型专项首次为 30.687 秒，颜色编辑后的补拍启动为 8.009 秒；这些非受控首次记录保留，不当作五组暖启动结论，也不声称冷启动问题全部解决。帧时间含 VSync／调度，不是纯 GPU 时间；显存为引擎监控值，不是专用分析器测量。

纹理估算按未压缩尺寸保守计，不以 GPU 压缩掩盖内容预算；地形共享原素材，不重复记为新文件。来源、哈希和导出指标见[manifest](../../assets/generated/village/3d/village-v4-manifest.json)和[全局来源](../../assets/generated/provenance.json)。

## 失败记录与人工边界

- `gray-probe.log` 使用程序化地面时受阻；灰模改用实际派生地形。
- `gray-native-probe.log`／`gray-diagnostic.log` 记录广场连接短坡停步；平顺新土坡后通过，不改角色坡度限制。
- `gray-graded.log` 的路线和院门通过，但快照测试未解除测试容器锁，桥头无法移动，退出码 1；测试解锁后实际模型整轮通过。
- `import-initial.log`、`import-compressed.log` 的 headless 编辑器退出有既有资源清理告警，不能当作清洁游戏专项。
- 早期普通时钟逐帧写图导致短片模拟时间与播放时长不同；其短片仅保留历史，最终使用固定 30 fps 重录，路线实测不使用录像数据。
- 第一份实际模型截图在 billboard 回退测试后未重新装回 3D 主角；其路径结果有效，画面保留为回退记录。最终补拍已恢复 3D 主角。

负责人对布局密度、手感、叶片和材料的视觉评价仍单列待确认；真实 Xbox／raw delta、目标硬件冷启动和性能没有冒充通过。没有新增任务、NPC、森林、室内或动画，没有提交、推送或导出游戏。本机角色及含角色截图／短片只限本机非商业使用。
