## 视觉复核与修正

- 初版被褥面片顶点未焊接，平滑法线出现明显格状反光，下垂区域还穿入床垫；已焊接重算法线、调整床沿圆弧与垂落形态。旧截图 `20261005-084349-sample/` 保留作为失败证据，后续图不应与其混淆。
- 首轮新旧店招重复且图像宽高比不匹配；已隐藏旧店招、按实体比例绘制新牌，并补背板及支架。纸面从正方形改为 1024×650，减少汉字压扁。
- 代表树延长了主干以连接高层枝条，叶片缩小、增加法线平滑；当前轮廓仍有重复分枝与片状叶感，不评为最终自然树冠。
- 补齐新纹理独立输出目录；初次导出错误写入 v7 下的新增纹理已移到本机过程归档，最终模型没有依赖这些临时文件。
- 第一次 Godot 启动因进程未继承用户 .NET 路径失败，随后在启动脚本显式设置 DOTNET_ROOT；首次样板探针编译的整型通知参数不匹配已修正。对应失败日志保留，最终通过记录单列。
- 图形运行只有 Terrain3D 调用废弃 interpolation API 的警告；无运行 ERROR。无头编辑器导入完成并退出 0，但退出时报告 1 个 DummyTexture／CanvasItem 和资源引用未释放，保留在 `import-final.log`，**不宣称全部日志零错误**；实际 GPU 资源加载、截图和测试已通过。
