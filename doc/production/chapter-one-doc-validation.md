## 纸面走查

以下是针对文档的叙事逻辑检查，不是运行时自动测试：

| 场景 | 文档中的继续路径 | 纸面结论 |
| --- | --- | --- |
| A1→C1、C1→A1 | 两件均交差才登记双人送货；主角主动邀请 | 两种顺序均先独自行动，加入时机一致 |
| A2、B1→B2、C2 交错 | 沈砚接受后开放，B2 只依赖 B1 | 无循环依赖；三条生活事务均有独立结果 |
| 必要链八种完成组合 | 细案给出八行条件表，仅 A/B/C 全真可登记 | 支线及领取报酬不会成为隐形条件 |
| 零支线、低关系、未买装备 | 两战要求基础可胜；没有陪练或钱数门槛 | 设计无强迫刷钱、恋爱或高关系条件；数值以后验证 |
| 邀请暂缓、两场战败撤退 | 回去再谈，战前安全点重试；关键物资保留 | 不丢主线；胜利后不重复生成遭遇 |
| T1 后提前询问彭师傅 | 如实否认，后续核对具体地点；T3 不重复假装惊讶 | 玩家主动询问不破坏人物诚实性 |
| T4/T5 两种核实顺序 | 登记/旧事及现场都核实后暂时结案 | 得到具体回答但无有效去向，不追加求救对象 |
| 重复交差、取消、未领奖 | 劳动完成、应付报酬、领取分开并各自一次 | 不重复推进；未领奖不阻止取箱或睡眠 |
| 章末支线与直接睡觉 | T6 后自由收尾，两种选择明确 | 不要求任务板全清，也不强制立即换章 |
