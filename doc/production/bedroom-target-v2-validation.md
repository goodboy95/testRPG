## 资产与本机性能

最终 manifest：454,362 三角面、43 个网格对象、32 个源材质 datablock（含保存修订时保留的材质），0 个角色、无运行时布料、`formalAdoption=false`、`visualApproval=false`。真实可见物件、阴影重绘和引擎整帧提交不是同一统计口径。

最终探针使用 RTX 2080 Ti、NVIDIA 591.86、1920×1080、关闭 VSync，固定门口视角预热后采 180 帧：

| 指标 | 结果 |
| --- | --- |
| process frame 间隔中位数／p95 | 1.439／2.494 ms |
| 引擎整帧 primitives | 2,244,754 |
| 引擎整帧 draw calls | 199 |
| 引擎 VideoMemUsed | 462,895,958 bytes，约 441.5 MiB |
| 引擎 TextureMemUsed | 430,269,978 bytes，约 410.3 MiB |

帧间隔为 `Time.GetTicksUsec()` 的 process 信号墙钟采样，不是 GPU timestamp，也不是长时间最坏场景帧时。显存为 Godot 渲染器分配统计，不是显卡驱动的全进程峰值；含当前窗口、autoload 和虽被隐藏但已加载的本机角色资源。不得把本机结果换算成 GTX 1060 的承诺。

`[固定约束]` 1080p／60 FPS 的 GTX 1060 目标继续保留，**目标 GPU 未实测**。大场景接入、LOD、连续漫游峰值及真实手柄另验。

## 实际截图修正

1. 初版 GLB 场景同时保存 imported instance 与新拥有的子节点，网格全部重复，导致玻璃仍投影、窗光只剩窄条、床品重影。已清除导入根 `SceneFilePath`，保存单一拥有层级，并加入源／运行时网格数量回归检查。
2. UV2 解包可能重排顶点，原 GLB 自动 LOD 索引不再适用。已另存无旧 LOD 索引的 full-detail 网格，缓存用 GLB 精确 SHA256 保护；独立审图固定使用完整精度，并在退出恢复 viewport 设置。
3. 木纹初版被重复线性化而过暗；已纠正 PNG sRGB 编码。降低纹理密度／法线强度，布料采用连续 UV，避免依赖密集纹理冒充结构。
4. 纸页背面朝上、表盘躲在钟壳后、表盘和封面 UV 阅读方向、笔穿入曲面纸页均按实际近景纠正；保留清晰原有图像与独立指针。
5. 初版窗外邻屋太近；已把景物推远并下降，保持真实多层几何。粗椭球树冠替换为分枝与 8,640 片双面叶片，窗边侧看有视差；窗外建筑仍只达到背景样板精度。
6. 最初 Cloth 仅与床垫碰撞，脚侧垂边穿床架；第一次修正把两层布面压到同一平面，产生自重叠斑点，失败截图保留。最终从修正前保存源恢复网格，用平滑附加位移保留厚度，木条穿插和大面积重叠已消除。
7. 最初自动路线用低强度模拟摇杆，低于既有输入 deadzone，停在首个短距离终点附近。已提高探针输入强度，实际走动组件和主游戏输入配置不改；最终完整路线通过。

## 美术判定和剩余差距

`[已实现]` 门口构图、柔软被子体积和下垂、独立家具结构、窗帘厚度、窗外视差、清晰表盘／封面以及烘焙光照链路已成立，床边、桌边、窗边、反向均有实际图像可检查。

`[可调整草案]` **尚不判定达到参考图美术质量**：墙面的暖反光和整体色彩仍偏灰；太阳投影边缘偏硬、亮部层次不够柔和；枕头压陷和布料缝线、部分褶皱与光照贴图近景小斑块仍需修；窗外屋面／门窗、盆栽叶形和山体过于简化，缺少参考图的自然生活层次。图像清晰不代表家具、灯光和布料的美术已经获批。样板保留供负责人比较，不据此自动替换正式住宅。

`[固定约束]` 负责人视觉／手感、GTX 1060、长时间走查、正式住宅接入尚未验收。当前作品来自脚本网格、实际布料求解与局部修正，未声称手工精雕模型或最终美术定稿。
