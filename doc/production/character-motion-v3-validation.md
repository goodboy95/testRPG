# 林晓雨流萤外观与双角色动作 v3 验收

> 2026-09-12；本机 Windows / Godot 4.6.3 .NET / Compatibility / RTX 2080 Ti。仅本机非商业，不提交、推送、分发或导出角色、制作源及含角色画面。

## 实现与边界

`[已实现]` 林晓雨在四室及洋房动态加载流萤“春日手信”外观，保留衣服与头发、不导入剑；玩家沿用原本机模型。两人各 12 段原地动作，分别制作步幅与周期，支持独立待机相位、连续步态、可取消转身及交互姿态。五区跟随改为平滑加减速与停止滞回，协作到位后才开始动作计时；模态、取消、失焦和重载清理按表现层规则执行。缺失模型回退 billboard，缺少可选动作回退待机。

本次不修改 Core、正式存档格式、剧情、答案或内容版本 6，不推进玩家静态候选。Legacy 保留原二维表现。实现与复现入口见[角色动作](../engineering/character-motion.md)。

## 本机画面对照

本机入口为 `outputs/character-motion-v3/review.html`。四个采集组为新版 1280×720、1600×900、1920×1080 和旧资产 1280×720 对照。每组五区共 63 张截图，覆盖双人正背面待机、移动、停止、反向转身、90° 转向、近镜头、四种玩家交互及三处晓雨协作。另有八种姿态、四个角度的 32 张双人模型近景。

最终共 252 张场景截图、32 张模型近景和 4 段视频；新版各 107.33 秒，旧资产对照 106.83 秒。`finalize_review.py` 核对每张场景截图尺寸、每段 MP4 的原生尺寸、四项源/运行时文件摘要及本地排除，输出 `review-manifest.json`。本机索引脚本语法检查通过。

原始截图及最终视频保留对应窗口尺寸，MP4 浏览版为 30 FPS。最初引擎按默认窗口输出 720p；最终使用 `record_native.py` 在每次启动前临时设置同档窗口覆盖值，运行后删除自己创建的 `override.cfg`，没有改变正式默认分辨率。录屏开启固定步进，耗时不能作为实时性能结论。

旧资产对照是原玩家 v2 动作与晓雨 billboard，使用当前路线及控制器，不能当作历史程序完整录像。协作截图使用专项相机及显式姿态请求，采用正式控制器的朝向：音乐室朝左观察、档案室朝右操作、礼堂面向机关。真实协作业务入口另由完整序章回归覆盖。

## 未验收与限制

- `[计划]` 负责人逐段观看录像确认自然度，尤其裙摆、头发、手臂穿插及近景动作；自动检查和若干静帧审阅不能代替这一项。
- `[已实现]` 当前使用中性表情。源模型的 80 个形变已检查，但 GLB 未输出表情/口型动画。
- `[已实现]` 手部为通用离线操作姿态，没有逐机关的运行时手掌吸附；不能声称手掌精确贴合录音机或拉杆。
- `[计划]` 真实 Xbox / raw delta、目标硬件冷启动与性能、完整人工盲测仍待验收。未导出发布包。

原始流萤目录、双方运行时镜像、制作源与本轮画面均已加入本地 Git 排除，导出配置排除 `tests/*`、`outputs/*` 与原始流萤目录。未提交或推送；用户原有工作副本变更保留。
