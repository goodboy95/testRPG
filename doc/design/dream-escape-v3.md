# 四室梦境密室 v3 设计冻结

> 状态：`[已实现·待人工终验]`，内容版本 5，冻结日期 2026-09-01。
>
> 本文冻结第三、第四室同步 3D 化后的规则与表现边界。幕后真相、现实初见、刺醒规则、白噪声母带和第一阶段结局未改变；完整人工盲走、设备、性能与导出仍未验收。

## 固定规模与兼容

- 四室合计保持 28 个结算谜题、34 件道具、11 个稳定安装槽、两轮短回访和 `ExitOpened` 终态。
- `DreamEscapeState.CurrentContentVersion` 为 5。进行中的 v4 梦境存档拒绝继续并要求重开；已完成的 v4 终态与无梦境 Legacy 存档继续兼容。
- 存档 DTO 不新增位置、镜头或机关表现字段。长期状态只保存稳定区域 ID、二维位置以及 Core 已有的物品、谜题、安装槽、线索和提示集合。
- 旧 `dream.archive.club_order`、`dream.auditorium.curtain_fly` 及其旧线索/目标进入退役目录，不得复用表示新含义。

## 第三室：档案兼广播室

- 空间约 12×9×4.2 米，分为档案架区、中央登记台、广播间和维修录音区。旧存档矩形 `Rect2(16,54,608,272)` 映射到约 11×8 米可移动平面；非法旧坐标解析到最近安全点。
- 恰好 15 个唯一 3D 交互目标，答案线索与对应机关至少相距 2 米。
- 新题 `dream.archive.signal_registry`：墙面规则与合唱、广播、美术、田径四份档案分别记录“上午/下午＋北/南”，按先时段、后方位得到“合唱—广播—美术—田径”。奖励仍为三角维护钥匙、红滤尺和陶瓷保险管。
- 抽屉矩阵保持 `C1—A4—D2—B3`，取得铜线和接带胶；保险丝保持“左—中—右”。
- 录音机自动安装校准带盘、摇柄和修复保险丝；晓雨只以当前场景脚本姿态保持带盘张力。剪辑计数器保持 `12—24—31—45`，取得第四室钥匙。
- 折角镜回访高柜仍取得档案室剪带。

## 第四室：旧礼堂

- 空间约 18×13×7.5 米，包含南侧入口、观众区、北侧舞台、侧后台、放映区、接带台和三控制台。旧存档矩形映射到约 17×11 米可移动平面。
- 恰好 15 个唯一 3D 交互目标，答案线索与对应机关至少相距 2 米。
- 新题 `dream.auditorium.line_set_balance`：安装幕布配重后，按 A/B/C/D 四组磨损刻度设置 `3—1—4—2`，幕布实时升起。
- 放映机保持“窗格—人物—校铃”，发放舞台钩杆、琴凳夹钥、折角镜和空盘芯。
- 第二次回访分别从教室、音乐室、档案室取得剪带；按“教室—音乐—档案”拼接并安装母带，播放器只输出已有白噪声并提供文字替代。
- 三控制台保持 `372`、木鱼—钢琴—三角铁—手铃、幕布—时钟—校铃—点名册。晓雨按住左侧机关后，主角操作右侧总闸进入 `ExitOpened`。

## 3D 表现与状态所有权

- `DreamArchiveRoomController3D`、`DreamAuditoriumController3D` 复用 `WorldArea3D`、Orbit 镜头、`PlayerController3D`、坐标映射、门动画和 `DreamCompanion3D`。洋房与四室均为 3D→3D 换场，镜头相对门方向只存在于转场上下文。
- 权威美术源为 `dream-archive-room-v1.blend` 与 `dream-auditorium-v1.blend`；运行时加载同名 GLB。场景使用 Filmic、实时冷暖灯和 ReflectionProbe，不启用 LightmapGI；碰撞由 Godot 独立维护。
- 持久外观只从 `SolvedPuzzles`、`InstalledParts`、物品和线索集合派生，不保存第二份门、幕布、录音机、母带或控制台状态。
- `DreamAreaTransientState` 只传递当前面板预览值和晓雨左机关姿态。面板关闭、换房或重载立即清除，绝不写入 `DreamEscapeState`。
- 旧第三/第四室 2D 控制器、Painter 和 Marker 已移除；第一室历史对照资产保留。本机受限 `mc_model` 不属于可分发资产，缺失时继续安全回退 billboard。
