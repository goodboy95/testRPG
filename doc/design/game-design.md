# 游戏设计规格

> 叙事方向更新：2026-09-13。新现实剧情见[剧情圣经](story-bible.md)、[章节流程](story-flow.md)与[第一章细案](chapter-one.md)。本轮仅文档重构；下述既有系统、Legacy 数据与 Core 规则不因章节方向调整而改写。

## 产品定位

`[固定约束]` 《雾山旧轨》是 Windows 单机剧情生活 RPG，当前梦境为 3D、Legacy 世界为 2D。`[计划]` 玩家扮演一直在村中生活、在附近读高中的普通学生，在近现代日常中帮助他人、建立关系并接触隐藏的奇异现象；前两章在村庄及周边，之后游历，让地方冒险与长期悬念并进。

- `[计划]` 第一章周六委托已有细案，第二章保留周日上午补办与下午返校接口；前两章故乡、之后游历。总时长、总章数、目的地与结局未定。旧 3–6 个月、3–5 小时和七个内容日属于历史预算，不作为新故事承诺。
- 当前目标：先完成和验证 60–90 分钟“四室旧校舍梦境”序章；旧 15–30 分钟“两日生活＋首次异象”切片只保留给旧存档和回归。
- 当前谜题结构：`[已实现]` 序章 v4（内容版本 6）：四室、12 组主谜题/19 个规则节点、31 件道具、11 个安装槽、一次集中回访；13 段序章对白经 Dialogue Manager v3.10.4 播放。目标 60–90 分钟仍待至少 3 名剧情 RPG 玩家盲测。 具体见[序章 v4](dream-escape-v4.md)。
- 核心主题：“信任先于证据，真相修复信任”。
- 玩家弧线：从熟悉的日常事务，逐渐走向愿意承担陌生问题的不确定性与选择后果；此前已经习惯帮助村民。
- 基调：青春奇幻冒险。日常互动应有轻快、熟悉和互相打趣，第一章在工具箱事件前没有异象，不强加声音或地质征兆。

## 核心循环

```mermaid
flowchart LR
    Explore["探索当前地方 / 接触生活"] --> Choose["聊天、帮忙、活动或调查"]
    Choose --> State["关系、承诺、事实与线索变化"]
    State --> Feedback["记录、人物回应、可继续的方向"]
    Feedback --> Explore
    State --> Battle["必要时进入非致命情境战"]
    Battle --> Feedback
```

`[计划]` 新剧情的行动围绕人物困难和各地故事展开；图示是叙事循环，不代表新现实事件已实现。自由度集中在行动顺序、关系、探索与调查，不因游历方向新增开放世界、农耕、制作、经营或通用犯罪系统。暴露与谨慎/救援仍是旧版规则，本轮保留代码，不要求每章使用。

## 第一章委托与经济

`[计划]` 第一章以广场任务板为入口：村民当面或通过收件箱提交署名事项与酬金，村长登记并统一结款。两件村内短活后主动邀请沈砚，三条必要日常链均交差后登记取旧工具箱。支线、关系高低、报酬是否领取均不是解锁条件；任务板不显示主支线分类、后台链名、前置条件与百分比，已接事项仍显示可理解的行动信息。

`[固定约束]` 父母两年前失踪、课余挣钱是人物背景。此前积蓄暂够生活，本章不扣生活费、不设最低收入，报酬可用于装备和治疗物品。交差、应付报酬、领取分开处理且各自防重复，不以额外刷钱维持基础可胜路线。

第一章任务卡与场景结果只在[第一章细案](chapter-one.md)维护；剧情结尾是正常排查后仍无有效方向，不另加需要回应的困难。

## 时间与日程

`[计划]` 新第一章采用同一个周六的早晨、午间、下午、傍晚阶段，由关键事情推进；自由探索、支线及战败不耗尽当天。工具箱排查后才开放结束当天的睡眠，玩家可继续支线或进入周日第二章。周日早上收到下午返校通知，上午续办剩余事项，跨章保留进度及未领报酬。下午学校事件与后续时间安排另行设计。

下列为 `[已实现·Legacy]` 的日历/移动计时行为，不是新第一章阶段制的已实现规则；本轮不改代码：

- 一天可活动时间为 08:00–23:00，按约 20 分钟移动时间设计。
- 只有玩家实际移动时计时；站立、对话、菜单、手册、事件和战斗暂停。
- 23:00 后停止普通 NPC 活动和时间推进，但不强制传送；玩家仍可移动、换图和回家。
- 睡眠进入次日 08:00，只改变日期，不自动推进主线。
- 旧“Day 1–7”属于历史剧情阶段；新章节不直接映射或改名现有日期/状态字段。玩家连续睡眠或晚调查时，关键事件仍应可继续；本轮不调整计时和日程规则。
- 日程以剧情覆盖优先、普通兜底随后；手册逐步记录玩家已经得知的作息和下一可见时段。

## 探索与交互

- 分区式小镇，Legacy 平面区域使用 8 方向自由移动和 4 朝向视觉复用。当前梦境洋房与四室采用固定俯角、自由水平环绕的透视第三人称，移动始终按屏幕方向解释；历史四方向正交方案只保留作实验对照。
- 邻近交互目标按距离、面向和稳定 ID 选出唯一对象；统一确认键。
- 支持键鼠及 Xbox 手柄，提示随最后输入设备切换。
- `[计划]` 前两章围绕故乡及周边逐步确定地图；第一章使用住宅、广场、活动室、修理铺、杂货铺，以及森林内林缘劳作点和取箱小屋等设计地点，新增地点及居民尚未接入，现有住宅/村庄仅独立预览。公司设施不再是必做地图；后续游历地点和资源预算未定。
- 不提供唯一任务箭头。事实手册给出人物习惯、地点、线索和可能方向，让玩家自己决定先后。
- 暂停菜单必须提供“返回当前场景安全点”，处理碰撞或转场卡住而不改变剧情。

## 关系与信赖

关系是有方向的 `SourceId -> TargetId`：

- `Affinity 0–100`：相处舒适度与个人亲近。
- `Trust 0–100`：在信息不足、风险或压力下相信并支持对方的程度。

UI 不显示数字：

| 数值 | 好感 | 信赖 |
| --- | --- | --- |
| 0–24 | 陌生 | 戒备 |
| 25–49 | 熟悉 | 接纳 |
| 50–74 | 亲近 | 认可 |
| 75–100 | 深厚 | 信赖 |

- 日常聊天、帮忙、共同活动和有限礼物主要提高好感。
- 守约、保密、承担风险、承认错误和提供真相提高信赖。
- 关系永不因天数或久未互动自动下降。
- 每名居民 1–2 个偏好礼物；同一礼物在同一好感阶段只生效一次。礼物不能提高信赖。
- 旧版 Core 救援同行资格满足任一：对主角信赖 ≥75；对林晓雨信赖 ≥75；或对两者均 ≥50。本轮保留判定，不作为第一章沈砚加入的预定门槛。
- 旧稿无人满足时可独自救援并获基础补给的安排保留作历史；新事件同样不得因低关系而软锁，具体回退随事件设计。

## 承诺

- 关键选项显式标记【承诺】，并立即写入手册。
- 承诺没有隐藏截止日，只能处于待履行、已履行、已解释或已违约。
- 玩家可以完成、主动解释或违约；终态不可再次改写。
- 主线不得要求承诺必须完成。失约改变关系和后续对白，但必须保留调查入口。

## 调查与反馈

手册分别记录：

- 已确认事实；
- 可向第三方出示的证据；
- 尚待调查的线索；
- 已知人物与作息；
- 当前承诺；
- 暴露征兆（当前 Legacy/旧版规则）；
- 按内容日排列的时间线摘要；
- 对话历史和已读状态。

普通事件由交互入口触发，不会因错过一次时段永久消失。危险预警优先展示，但仍由玩家确认进入。关键事实应来自始终可访问的世界交互或多个替代来源，不能只依赖关系、礼物或单个 NPC。

## 暴露与路线（旧版规则基线）

`[已实现]` 当前 Core 保留暴露和路线判定，Legacy 切片含首次风险选择。`[可调整草案]` 下列完整路线是旧稿素材，尚未做成完整可玩路线，也不约束新第一章或旅途；本轮不删除其状态、测试或枚举。

林晓雨的能力暴露分四阶段，UI 不显示数字：

1. 无人注意；
2. 疑似监视；
3. 重点怀疑；
4. 身份确认。

只有公开使用能力、进入敏感设施、在被跟踪时继续高风险调查等明确选择提高阶段。每次风险选择前后都要提供可感知反馈，例如陌生人观察、公司打听、房间被搜查或路线出现重复车辆。

- 身份未确认：进入谨慎路线，玩家可观察巡逻、秘密潜入、取证并破坏一个仪式节点。被发现转入战斗，不立即失败。
- 身份确认：林晓雨被绑架，进入救援路线。公司伪造其破坏工程、引发异常的证据，只为削弱玩家的救援支持并拖延行动。
- 救援证据完整会修复全镇关系并奖励同行者；证据不全只修复原本高信赖居民，其余人需要后续说服。
- 救援路线有更高社会回报，但公司保住一个仪式节点，终战多一个阶段；谨慎路线削弱终战并保存更多补给，但没有全镇关系跃升。

## 对话与恋爱

- 对话支持历史、自动播放和只跳过已读文本。
- 选项使用完整意图文本，不用模糊的“是/否”；只有承诺、隐瞒、冒险等性质加标签。
- 林晓雨和沈砚保留恋爱候选基础，但新剧情的关系事件与确认时机待设计。晓雨第一章现实不出场，不能按旧前期三选一安排她的活动。
- 确认一段恋爱后另一候选自然转为友情、不制造三角惩罚的原则保留；旧 Day 6 不再是新剧情确认时点。
- 周明仅发展深度友情，保留知识与文本方面的人物基础；不预设终战职责，也不把友情写成“次等路线”。

## 战斗与成长

`[计划]` 第一章主路径安排两处普通动物必经情境战：森林内林缘物资任务的山猴、森林取箱途中护幼的野猪；分别围绕保护物资、配合驱退和安全通过。村内没有敌对遭遇，另有两次自愿的有限陪练支线，输赢均可完成陪练。村内外景先按[设计细案](village-exterior.md)规划，森林与小屋另行设计。无随机遭遇和刷怪，无动物异象；基础配置、低关系和未做支线也有可胜路径，允许撤退重试。

下列为继承的设计基线；当前运行时仅有 Legacy 单场情境战及部分 Core 判定，第一章战斗、商店和旅途成长尚未接入：

- 战斗切换到独立侧视情境场景；主角加最多两名伙伴。
- 旧版完整流程曾规划 8 场、单流程约 6–7 场；新章节的场次与分布未定，仍不新增随机遭遇和刷怪。
- 核心行动：调查、保护、安抚、破坏装置、制服、撤退；敌人和公司普通成员尽量非致命处理。
- 关系解锁联携优势，但任何关系状态必须有基础可胜路线。
- 战败可立即重试或撤退到战前安全位置；第一章不因战败推进到次日，不能锁死主线。
- 等级 1–10，经验来自任务和有限战斗；固定等级解锁技能，不做技能树。
- 每人工具槽和饰品槽、帮忙报酬保留作设计基线；暑假预算不再用于新第一章，旧 15–20 件总量是旧稿预算，新旅途内容另行估算。
- 故事模式下战斗不损失意志，但仍保留解谜和行动选择。

## 地方结果与长期悬念

`[计划]` 前两章的地方冒险需要在离村前产生实际帮助他人的结果，同时形成向外走的理由。第一章帮助人的结果来自正常日常委托；工具箱核实无果、留下疑惑即收尾，不揭示来源。第二章先保留周日上午补办与下午返校的接口，不承担压缩完成旧七日故事的任务。后续各地故事和贯穿悬念并进，最终敌人、总章数与结局尚未确定。

`[可调整草案]` 旧多阶段封印仪式、三名伙伴的固定职责与三档结局见[历史剧情圣经](story-bible-legacy.md)。这些只作素材；现有 Core 判定不改，但不决定新终局。

## 内容与资产目标

- `[计划]` 依[第一章细案](chapter-one.md)写场景与对白草稿，再估算角色、地图与资源；有意留白的来源真相不能自动补齐。旧 20–25 个事件组及固定人物事件配额是历史预算，新旅途总量未定。
- 32px 地块、48px 行走角色、四向各四帧；战斗只做关键动作；对话半身立绘加少量表情。
- AI 资产从风格锚点派生并记录来源；音乐和音效离线生成与剪辑，不制作完整语音，只用短促语气音。

## 无障碍与验收目标

基础无障碍包括文字速度、字号、按键重映射、减少闪烁、震动开关、高对比交互提示、无边框全屏和故事模式。

熟人无需讲解应能：找到目标 NPC；理解承诺和风险征兆；完成低资源路线；并指出至少两项“自己的行为改变了后续反馈”。如果做不到，暂停扩充地图和剧情，先修复关系、风险提示和调查手册。
