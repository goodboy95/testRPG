# Day 1–7 场景级剧情流程（完整剧透）（历史参考）

> `[可调整草案]` 历史参考，归档于 2026-09-12 醒后剧情重构。本文保留旧版公司、封印与七日终局方案；下文的“固定约束”“计划”和实现标签记录归档前的语境，不是新现实主线的制作指令。当前方向以[剧情圣经](story-bible.md)和[醒后剧情流程](story-flow.md)为准；源码现状以[当前实现](../engineering/current-implementation.md)为准。禁止据此恢复晓雨第一章现实出场、旧友重逢或将旧路线直接接到新游戏。

## 使用说明

新游戏先进入四室旧校舍序章；序章完成后的现实承接属于第二阶段，当前构建尚未进入 Day 1。Day 表示内容阶段，不是不可逆的日历截止。除明确的当日氛围对白外，主线事件应由剧情事实和玩家主动调查推进；玩家睡过几天后仍可进入当前内容阶段。

表中旧 Day 1–2 是仍可由旧存档进入的 `[已实现·Legacy]` 切片，不再代表新游戏正式剧情；其中“四人重逢”和晓雨旧友关系必须在后续重写。Day 3–7 是 `[可调整草案]`。

## Day 5A：谨慎潜入 `[可调整草案]`

### C5-01 观察巡逻

主角与可选彭师傅在山林高处记录换班、照明和通风井。玩家可花时间取得完整路线，或立即行动保留更多夜间时间。任何关系状态都能得到一条基础入口；高信赖角色提供捷径、补给或额外证据。

### C5-02 公司设施潜入

| 项目 | 规格 |
| --- | --- |
| 目标 | 复制真实作业日志、确认领袖私令并进入第二节点控制室。 |
| 情境行动 | 调查终端、切断警报、制服巡逻、保护证据；不提供偷窃/伤害无关人员的通用系统。 |
| 被发现 | 转入非致命战斗；胜利后继续，撤退保留已取得证据并可次日重试。 |
| 成员 | 出示异常伤情和伪造审批可让一组普通成员停手，记录为倒戈。 |

### C5-03 破坏仪式节点

周明确认顺序、沈砚开启检修机关，晓雨在远处或屏蔽环境下稳定共鸣。成功将 `RitualNodesRemaining` 减少 1，并保存较多终战补给。失败不会转成绑架路线，而是节点部分损坏、补给消耗增加，允许重试或以较难状态继续。

## Day 5B：绑架救援 `[可调整草案]`

### R5-01 失联与伪证

公司公布剪辑录音、伪造施工照片和“晓雨引发事故”的声明，要求居民等待调查。`[固定约束]` 这套舆论只用于阻止主角及时救人、隔离证人并拖延仪式，不是组织目的。

罗记者指出材料不足以定罪，也不足以立即公开反驳。居民根据既有信赖决定是否相信主角并承担行动风险；他们可以拒绝同行，但不参与迫害。

### R5-02 召集同行者

逐一读取居民对主角/晓雨的有方向信赖：任一 ≥75，或两者都 ≥50即可同行。同行者最多形成主角加两名战斗成员，其余提供外围支援。无人满足时，旧宅门口出现匿名基础药品、设施草图和撬具，玩家可独自出发。

### R5-03 突破、取证与救人

| 阶段 | 目标与选择 |
| --- | --- |
| 外围 | 从彭师傅路线、乔姨旧工牌或基础通风井三种入口选一。 |
| 资料室 | 取伪证制作记录、真实作业日志或成员名单；时间/资源不足时可只拿部分。 |
| 成员对峙 | 用证据说明领袖隐瞒唤醒计划；可策反、绕过或非致命制服。 |
| 共鸣室 | 保护晓雨的自主判断，解除装置而非强迫她继续歌唱。 |
| 撤离 | 救人优先或回头取完整证据；前者安全但社会修复较慢。 |

救援成功且证据完整：全体核心居民对主角好感 +18、信赖 +15，同行者额外信赖 +12并记忆“在无证据时同行”。证据不全：仅原本信赖 ≥75 的居民好感 +8，同行者仍获额外信赖。公司保住一个节点，终战增加阶段。

## Day 6：后果、关系和终战准备 `[可调整草案]`

### D6-01 分线后果汇合

- 谨慎线：将作业日志交给罗记者，保护倒戈成员身份，确认已削弱节点；居民关系按既有状态缓慢变化。
- 救援线：处理晓雨伤情和伪证余波；证据完整时举行公开说明，证据不足时逐户补证，不强制全镇立刻道歉。
- 两线都确认领袖将在第三节点完成唤醒，并发现守护者家族真实病史。

### D6-02 居民支援与最后证据

五名居民各有一个可完成的支援确认：乔姨准备避难点；何医生建立共鸣停止标准；温老师公开校史更正；罗记者封存证据；彭师傅关闭施工设备。低信赖时角色仍履行职业伦理，但不承担额外危险。

### D6-03 伙伴关系收束

| 角色 | 场景结果 |
| --- | --- |
| 林晓雨 | 共同确定终战停止信号；若现实相识后的信任已建立且关系足够，可含蓄确认恋爱。否则以互相信赖的伙伴关系结束。 |
| 周明 | 决定公开多少家族日记；高信赖时接受让当事人共同解释，而非只发布文本。 |
| 沈砚 | 将怀表开启节点的责任从家族私物转为共同选择；关系足够时可确认恋爱。 |

确认一条恋爱后另一候选自然进入友情收束，无扣分。未确认恋爱不影响终战可完成性。

### D6-04 作战会议

玩家选择最多两名上场伙伴并安排居民支援。手册展示三项关键事实、剩余节点、证据完整度、倒戈者和可用支援，但不直接显示结局档位。缺少任何资源都要给基础方案。

## Day 7：封印终局 `[可调整草案]`

### D7-01 山体异变与进入遗迹

地层共鸣导致停电、落石和重复梦境。居民支援分别减少医疗、疏散、补给、舆论和设备危机。谨慎线通过已破坏节点缩短入口；救援线需要额外处理公司保住的节点，但可能有更多居民和倒戈成员协助。

### D7-02 多阶段仪式战

| 阶段 | 核心角色 | 基础可胜行动 | 优势来源 |
| --- | --- | --- | --- |
| 共鸣保护 | 林晓雨 | Guard、清除干扰装置 | 何医生、关系联携、故事模式。 |
| 历史判断 | 周明 | 调查碑文、按顺序试错 | 真历史事实、温老师档案。 |
| 节点开启 | 沈砚 | 校准怀表、手动开启 | 怀表激活、彭师傅设备支援。 |
| 社会危机 | 居民 | 疏散、供给、记录、关闭机器 | 各居民信赖与个人事件。 |
| 最终稳定 | 三伙伴 | 保护、安抚、破坏、承担代价 | 剩余节点、证据和团队状态。 |

步骤失误增加资源消耗或代价，不直接锁死。战败可从阶段检查点重试或回到战前准备。

### D7-03 领袖对峙

玩家必须同时承认守护者家族所受伤害，并拒绝以灾难追责。证据 ≥4、存在倒戈成员且真历史恢复时，可让领袖主动停止最后命令；否则其顽抗并被非致命制服。两种结果都进入责任调查，区别体现在成员伤亡风险、供述和尾声，不改变“必须担责”。

### D7-04 结局判定

| 档位 | 条件与表现 |
| --- | --- |
| 完整重新封印 | 三项关键事实齐备、节点 ≤1、证据 ≥4、至少 3 名居民对主角信赖 ≥75。建立公开、轮换、可照护的新封印制度。 |
| 重大代价后暂时压制 | 三项关键事实齐备、节点 ≤2。伙伴以健康、设施或长期照护为代价获得缓冲时间。 |
| 仅阻止当前苏醒 | 关键条件不足，但成功终止本次仪式。异常未来可能返回，主角留下继续调查。 |

三档都能完成游戏，不把低资源路线写成“坏档读死”。

### D7-05 组合尾声

按恋爱确认、周明公开选择、五居民支援、倒戈成员、领袖是否主动停止、救援证据完整度生成短尾声。最后固定回到旧宅或车站：主角不再把小镇当作暑假旁观对象，而是主动参与后续记录、照护和责任追究。
