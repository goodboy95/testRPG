> 方向确认：2026-09-13；2026-09-14 更新村庄／森林地点。本轮已批准村中高中生、周六委托与旧工具箱方案，替代 09-12 的返乡/求助信入口。本文件保存世界观与人物边界；[剧情流程](story-flow.md)保存章节概要，[第一章细案](chapter-one.md)是详细设计唯一正文。现实章节尚未接入。

## 故事方向

`[计划]` 一直生活在村中的普通高中生，在周六日常委托中与好友结伴，章末取回一只早年遗失在外地的工具箱，遇到无法解释的委托来源。村庄及周边是前两章的主要活动地点；此后走向外地，在不同地方参与各自的人物故事，同时缓慢推进贯穿旅途的悬念。

`[固定约束]` 世界保持架空近现代东亚的日常底色，奇异现象隐藏在人们的生活之中。故乡保留山间、旧铁路与生活据点的背景。本文“村庄”指新的前两章叙事舞台；源码、场景及 Legacy 文档中的“小镇”名称和地点 ID 本轮不改。

`[计划]` 每个地方的冒险应有自己的生活、人物困难和阶段性结果。离开故乡前，玩家应当获得实际帮助了某个人的满足感，并对外界有所期待。总章数、总时长、后续目的地、最终敌人和结局尚未确定，旧七个内容日不再限定新故事。

## 主题与人物写法

- `[固定约束]` 保留青春奇幻冒险的基调，以及“信任先于证据，真相修复信任”的主题基础。年轻人之间有日常、玩笑、分歧与逐渐形成的默契；信任允许求证，也允许承认判断错误。
- `[固定约束]` 主角已经习惯帮助村民，其成长从熟悉的日常事务走向愿意承担陌生问题的不确定性与选择后果。保留观察、倾听和谨慎，通过具体行动表现，不写成此前从不帮人的旁观者。
- `[固定约束]` 核心居民本质善良，可以犹疑、误解或不愿承担额外风险，不写成集体猎巫、私刑或主动迫害伙伴的群体。真相和关系变化需要具体经历，不能靠一次演讲自动解决。
- `[固定约束]` 保留现有人物的性格与关系基础；梦中合作不直接赋予现实中的亲密、敌意或恋爱关系。低关系、失约、错过时段、撤退和战败仍须有继续路径。

## 主角与梦境

`[固定约束]` 主角一直生活在村中，在附近学校读高中，熟悉村庄和村民。父母两年前外出务工后失踪；主角独居，由村中长辈照应，放学后及周末帮村民做事挣钱。旧宅是生活据点。长处是观察、倾听与核对说法，缺点是面对陌生问题容易等到完全确定才行动；不保留大学民俗专业经历。姓名与称谓仍可修改，既有外观和性格底色保留。

`[固定约束]` 父母失踪是长期牵挂，真相及是否成为主线有意留白。此前积蓄暂时够生活，本章不扣生活费、不设收入门槛；报酬用于装备与治疗物品。

`[固定约束]` 正式视觉锚点继续为偏男性化的普通高中生：短深色头发、砖红色夏季上衣、深蓝长裤和帆布鞋；不因新旅途方向新增夸张体格、武器、超自然装饰或性别化对白分支。本机受限人物外观不改变这一基线。

`[固定约束]` 主角与林晓雨此前是见过或听说过、但没认真交谈的同村人。晓雨很久以前搬来，在这里有自己的生活。梦境是两人第一次深入交流和合作，不再使用“现实此前从未见过”作为新剧情约束。

`[已实现]` 当前序章从主角独处开始，第二室隔门交换观察，开门后互报姓名并同行。13 段对白、四室机关和梦中记录保留；互报姓名不等于现实旧友重逢，也没有写入现实关系值。新方向本轮不改写已播放对白。

`[固定约束]` 第一章现实中不出现晓雨，也不让她远程加入调查、提供答案或与主角共同冒险。主角在这一章只保留梦的模糊印象，不作为调查线索；现实关系在后续相处中重新建立。

`[计划]` 梦境成功后的正式信息、封存排列、醒后载体与结算承接仍待单独设计。本轮不生成封存正文、解码入口、醒后载体或工具箱与梦境的因果关系；保留前期不解码、不将预留封存信息登记为事实/证据/线索的边界。当前机制仍止于 `ExitOpened`，刺醒仍为 `CompletedPin`；醒后新剧情尚未接入。

## 伙伴与居民

### 沈砚

`[固定约束]` 主角的旧友和恋爱候选，擅长用玩笑缓解紧张，保留家传怀表及个人手艺的背景，也有担心自己作为普通人帮不上忙的一面。

`[计划]` 第一章先独自完成两件村内短活，随后主角为双人送货主动邀请沈砚，再结伴处理日常与取箱。沈砚能打趣、提出不同解释和实用判断，怀表本章不发挥超自然功能。

`[可调整草案]` 沈砚周末有空，也想攒钱添置修理工具，在活动室门前受邀，接受共同送货与约定分酬；具体互动见[细案](chapter-one.md)。

### 林晓雨

`[固定约束]` 保留对声音与共鸣敏感、容易独自承受并逞强、需要学会表达边界与接受帮助的人物基础，以及恋爱候选身份。她在村庄有自己的熟人、习惯与烦恼。

`[计划]` 第二章设计时再确定她的现实出场与参与方式，不预定章首入队或具体关系事件。她的能力如何关联新主线仍待设计；旧稿“固定绑架目标”和终战共鸣职责不再约束新剧情。恋爱不以被救作为交换。

### 周明

`[固定约束]` 保留旧友、重视文本与整理、容易忽略他人感受的性格基础，以及家族口述史和隐写日记的背景；只发展深度友情，不把友情视为次等路线。

`[计划]` 其正式参与时机和个人故事另行设计，不沿用旧稿四人同时重逢、第一章三选一活动或预定终战知识职责。

### 乔姨与其他居民

- `[固定约束]` 乔姨保留杂货铺店主、熟悉村中生活与消息、不会凭传言定罪的人物基础。
- `[计划]` 乔姨安排村内订货与双人送货，不再承担求助信收信人职责。村长在广场附近登记委托、代管酬金、提供必要照应；署名纸条及酬金可以投入日常收件箱。
- `[可调整草案]` 何医生、温老师、罗记者与彭师傅保留医生、地方史教师、记者、熟悉旧线路与现场工作的居民等人物素材。其他人物的参与另行设计；彭师傅本章采用修理铺与旧工具箱主人的安排，旧终战支援分工不直接沿用。“送货途中丢失时间”的旧候选未采用。
- `[已实现]` 当前角色 JSON 只有主角、晓雨、周明、沈砚、乔姨五个定义；其他居民有 Core ID 预留，不代表已经出场或可入队。

## 第一章与第二章的已定前提

`[固定约束]` 第一章是同一个周六：醒来后先独自办两件短活，前中期邀请沈砚，展开三条独立必要日常链。三链均交差后登记工具箱委托，支线和领钱均不影响解锁。任务链是后台逻辑，玩家只见具体事项；工具箱之前都是正常生活。

`[固定约束]` 第一章活动区域为村庄与附近森林，村内没有敌对遭遇，自愿陪练保留。林缘劳作链的送饭与取物都在森林入口以内，山猴、野猪两场遭遇都在森林；村内家禽寻找不引入战斗。村庄自然生活感及建筑／院落设计见[外景细案](village-exterior.md)，森林和小屋另行设计。

`[计划]` 有两处普通动物必经战斗，以及独立陪练、照看院子、寻找失物等支线；可撤退重试，低关系、未做支线和未购买装备不锁死主线。具体任务卡和失败恢复只在[第一章细案](chapter-one.md)维护。

`[固定约束]` 署名彭师傅的委托与酬金通过日常收件箱登记，主角从附近森林小屋取回他早年遗失在外地的普通工具箱。本人否认委托，正常核实后没有有效方向，留下疑惑即实质结章；可以继续支线或回家睡觉。提前询问须如实否认。来历不绑定晓雨、父母、梦境、组织或终局，不额外设置需要拯救的人或隐藏信件。

`[计划]` 周六按剧情阶段推进，探索不会耗尽当天。第二章周日早上收到下午返校处理临时事务的通知，上午可以继续未接或未完成的周六支线并保留进度、结款状态；学校事件及下午之后事项安排有意留白，不默认全部作废或无限期保留。
