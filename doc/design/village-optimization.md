## 第一轮：赶路体验

`[已实现]` 村庄 v2 室外默认速度为 4.2 米/秒，正式醒后探索与独立 v2 预览共用。住宅、梦境及显式 `--village-v1` 仍为 3.1 米/秒，Shift 慢走为 1.4 米/秒，摇杆连续调速。既有步态按实际位移播放，原始慢跑动作的 3.1 米/秒参考值不随场景调速改写。

`[固定约束]` 本轮只调整赶路速度与相应测试、文档。24 栋建筑、道路、地形、桥梁、镜头参数、Blend／GLB 和纹理不修改；不新增快跑键、体力、速度设置或自动提速区域。Core、SaveEnvelope v1、梦境内容版本 6、位置存档含义不变；正式旧村庄档恢复后采用新速度。第一章委托尚未接入。

## 第二轮：地形插件与局部样板

`[已实现]` 本轮已完成 Terrain3D 1.0.2 安装与三处独立样板：家门外道路、广场边缘、南桥西侧溪岸。采用有人维护的乡村方向、免费 CC0 材质及少量草簇碎石。详细数据、编辑方法和边界见[地形样板](../engineering/village-terrain-sample.md)，实际测试、同机对照与待人工确认项见[验收](../production/village-terrain-validation.md)。

`[固定约束]` 四区域承载整村基础地面，仅三处精修。样板制作轮保持正式入口不变；负责人随后确认采用，当前正式游戏和默认 v2 预览已切换，原 v2 地形可用 `--village-original-terrain` 回归，v1 保留。建筑、道路中心线、双桥与住宅保留；没有森林、任务、建筑新贴图、水面特效、Core 或存档变更。

`[已实现]` 负责人确认后已采用现有样板数据并接入正式安全落点恢复，见[采用验收](../production/village-terrain-adoption.md)。`[计划]` 全村其余地形的精修另行规划。全村裸露草地在样板入口采用了新的基础材质，这不等于全村已经精修。森林另行设计。

## 第三轮：建筑材质样板

`[计划]` 先做杂货铺和修理铺，确认后推广其余建筑。浅抹灰、砖石墙脚、灰瓦、旧木和棚布分别建立有合理物理尺度的材质，避免继续用同一种抹灰细节代替不同材料。

图像生成用于无透视、无烘焙阴影的基础颜色和局部磨损素材；需要另行制作或校正无缝拼接、UV 尺度、法线与粗糙度，不能把生成的明暗直接当作真实高度。墙脚、雨水流经处、门窗边缘与搬运接触处分别处理磨损，保持自然朴素和有人维护的生活感。

采用当前绘图工具时，保存提示词、参考、日期、可用参数与后处理记录；模型以工具实际返回信息为准，未披露则明确记为未披露，不声称使用 GPT Image 2.5。若后续必须指定型号，再单独确认可调用渠道。本轮没有调用绘图工具或生成贴图。

材质样板使用现有夏日上午光照，在近景、正常玩家视角及重复铺贴的远景下检查纹理接缝、颜色、闪烁与重复感。使用独立资产版本，保留可编辑源与旧版回归；不使用旧构建器覆盖精修源。

## 制作顺序与交接

`[计划]` 完成赶路验收后，依次讨论地形样板、建筑材质样板的具体制作范围。地形样板已由后续授权实施；正式采用已获确认；全村其余精修与建筑材质仍待下一轮确认。

沿用整村预算：120 万三角面、600 可见网格、64 材质、100 MiB GLB、384 MiB 纹理估算。插件若改变资源组织方式，需要给出可比较的总资源预算，不能仅检查拆分后的单个文件。所有采用素材继续维护来源与许可；本机角色及含角色录像只限本机使用，不提交、推送、分发或导出游戏。
