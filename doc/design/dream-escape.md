# 四室梦境密室规格

> 文档状态：`[已实现·第一阶段]` 规则、场景、背包、记录、提示、存档、刺醒与出口完成页。正式信息、纸条奖励、现实初见和 Dialogue Manager 对白为 `[计划·第二阶段]`。

## 叙事边界

- 新游戏在姓名确认后直接进入旧校舍，不在标题、HUD、背包或确认框中使用“梦境”“醒来”“跳过”等揭示词。
- 第一室只有主角；第二室器材间打开后，主角与林晓雨初次见面，此后共同移动。双方在现实中此前从未见过。
- 大头针确认只警告“永久失去尚未弄清的信息”。确认后才揭示梦境，清空梦境物品并永久结束本周目奖励资格。
- 出口开启是第一阶段机制里程碑，不是正式逃出；不得生成占位信息、现实纸条或 `CompletedEscape`。

## 空间与谜题链

| 区域 | 首次解法 | 回访/后续作用 | 开放结果 |
| --- | --- | --- | --- |
| 走廊 | 主角出生在第一室，但可直接从内侧进入走廊；钥匙打开第二室。 | 可随时返回已开放房间；第四室门在走廊提交广播序列。 | 顺序开放四室。 |
| 第一室·旧教室 | 拾取粉笔，对黑板使用，显出“窗—钟—值日表”的观察顺序；分别观察三扇窗格划痕、停在 7 点的时钟和圈出的值日表第 2 项，输入 `372` 打开教师桌并取得第二室钥匙。 | 第三室取得维护钥匙后打开地图柜，获得合影；红色透明尺显出 `B2—D1—A3—C4`。 | 第二室钥匙与合影线索。 |
| 第二室·音乐教室 | 粉笔显出音板编号，输入 `1—4—2—3`，救出林晓雨。三处辨听组合为“木鱼—钢琴—三角铁—手铃”。 | 使用合影坐标打开点名柜，取得录音带与摇柄。 | 第三室开放。 |
| 第三室·档案兼广播室 | 阅读归档规则，按“合唱—广播—美术—田径”排列，取得维护钥匙与红尺。 | 先装录音带、再装摇柄，得到“窗帘—时钟—校铃—点名册”。 | 第四室开放。 |
| 第四室·旧礼堂 | 三块控制板分别复现 `372`、乐器序列和广播图标序列。 | 林晓雨按住左侧机关后，主角操作右侧总闸。 | 状态变为 `ExitOpened`，显示第一阶段完成页。 |

错误答案、错误道具、在错误区域使用和重复操作均不消耗物品、不改变机关状态。有效操作后自动保存。

## 背包、记录与提示

- 梦境背包与现实 `InventoryState` 完全分离。选中道具是临时 UI 状态，不写入存档。
- 初始常驻大头针不可丢弃；其他七项物品按谜题链获得。消耗品仅在正确目标成功使用时移除。
- `I`、`Tab` 或 Xbox `X` 打开分页面板。救出林晓雨前只有“物品/记录”，加入后才出现“与晓雨商量”。记录保留已观察事实与声音/颜色的文字、形状或波形替代。
- 选中普通道具后面板自动关闭，场景提示显示将使用的道具；再次选择同一道具可取消。大头针只提供独立的“对自己使用”操作。
- 林晓雨加入前 Core 与 UI 都不提供提示。加入后，每个已发现未解机关有 0–3 级：目标提示、关联提示、近答案提示，无惩罚。
- 谜题面板使用可聚焦按钮、逐项撤销、清除、取消和确认操作；数字锁支持数字键直输，字号继承 100%–150% 设置。

## 美术表现

- `[已实现·实验分支]` 第一室以 1672×941 构图原图生成 640×360 运行时背景，地图柜、教师桌和十张学生桌使用透明裁片进行 Y 排序；模块化 `TileMapLayer` 版本仍保留用于分支对比。
- 第一室不使用悬浮文字标注机关。接近目标时显示暖琥珀轮廓；高对比设置改用黑白双层轮廓，操作文本仍由底部提示承载。
- 主角脚部与墙、柜、教师桌、十张学生桌使用真实 2D 碰撞；右侧门洞和主要过道保持通行。旧坐标落在障碍物时只通过 `GameSession` 修正到最近安全点。
- 粉笔、黑板、教师桌和地图柜的外观直接由 `DreamEscapeState` 派生，不保存第二份表现状态。低频尘埃持续移动；亮度漂移周期为八秒且幅度不超过 4%，开启“减少闪烁”时固定亮度。
- 主角与林晓雨使用 32×48 单帧、四方向各四帧的 128×192 精灵表；方向行固定为下、左、右、上。晓雨暂时只在既有同行位置显示，不实现跟随寻路。
- 像素图集与原图遮挡层均由离线 Pillow 脚本确定性生成和校验；实验分支正式采用的原图、派生背景、遮挡层及参考来源统一记录在 provenance。

## 状态与结算

`DreamEscapeState` 保存当前区域/坐标、物品、已解机关、开放区域、线索、提示等级和晓雨加入状态。状态机预留：

```text
InProgress -> ExitOpened
InProgress -> PinPendingWake -> CompletedPin
预留：EscapePendingWake -> CompletedEscape
```

第一阶段正式产生的终态只有 `ExitOpened` 和 `CompletedPin`。旧 v1 存档没有 `DreamEscape` 字段时按 Legacy 两日切片载入，不提升存档格式版本。
