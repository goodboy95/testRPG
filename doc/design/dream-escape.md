# 四室梦境密室规格

> 文档状态：`[已实现·第一阶段]` 规则、场景、背包、记录、提示、存档、刺醒与出口完成页。正式信息、纸条奖励、现实初见和 Dialogue Manager 对白为 `[计划·第二阶段]`。

## 叙事边界

- 新游戏在姓名确认后直接进入旧校舍，不在标题、HUD、背包或确认框中使用“梦境”“醒来”“跳过”等揭示词。
- 第一室只有主角；第二室器材间打开后，主角与林晓雨初次见面，此后共同移动。双方在现实中此前从未见过。
- 大头针确认只警告“永久失去尚未弄清的信息”。确认后才揭示梦境，清空梦境物品并永久结束本周目奖励资格。
- 出口开启是第一阶段机制里程碑，不是正式逃出；不得生成占位信息、现实纸条或 `CompletedEscape`。

## 空间与谜题链

| 区域 | 首次解法 | 回访/后续作用 | 开放结果 |
| --- | --- | --- | --- |
| 走廊 | 主角出生在第一室，但可直接从内侧进入走廊；钥匙打开第二室。 | 可随时返回已开放房间；第四室门在走廊提交广播序列。 | 顺序开放四室。 |

| 第二室·音乐教室 | 粉笔显出音板编号，输入 `1—4—2—3`，救出林晓雨。三处辨听组合为“木鱼—钢琴—三角铁—手铃”。 | 使用合影坐标打开点名柜，取得录音带与摇柄。 | 第三室开放。 |

错误答案、错误道具、在错误区域使用和重复操作均不消耗物品、不改变机关状态。有效操作后自动保存。

## 背包、记录与提示

- 梦境背包与现实 `InventoryState` 完全分离。选中道具是临时 UI 状态，不写入存档。
- 初始常驻大头针不可丢弃；其他七项物品按谜题链获得。消耗品仅在正确目标成功使用时移除。
- `I`、`Tab` 或 Xbox `X` 打开分页面板。救出林晓雨前只有“物品/记录”，加入后才出现“与晓雨商量”。记录保留已观察事实与声音/颜色的文字、形状或波形替代。
- `Tab` 使用真实 Tab 键值，不再与 Backspace 共用或误绑；背包开关在梦境输入前置阶段处理，因此即使分页按钮持有焦点也能再次按 `Tab` 关闭。
- 选中普通道具后面板自动关闭，场景提示显示将使用的道具；再次选择同一道具可取消。大头针只提供独立的“对自己使用”操作。
- 林晓雨加入前 Core 与 UI 都不提供提示。加入后，每个已发现未解机关有 0–3 级：目标提示、关联提示、近答案提示，无惩罚。
- 谜题面板使用可聚焦按钮、逐项撤销、清除、取消和确认操作；数字锁支持数字键直输，字号继承 100%–150% 设置。
- 3D 游玩时鼠标常驻捕获并隐藏；Esc 打开梦境暂停，背包、谜题、确认框、转场或窗口失焦会显示指针并锁定世界输入。关闭模态后恢复捕获；若指针意外可见，点击游戏画面可重新捕获。暂停菜单提供继续、设置、返回标题和二次确认退出；标题页同样可正常退出。

## 美术表现

- `[已实现·待视觉终验]` 第一室是 9.6×7.2 米、无天花板的完整四墙房间，含可见关闭教室门、西侧窗、墙上机关、教师桌、地图柜和十组共享网格课桌椅。精修 v2 的两套 2048² PBR 图集、旧水磨石方砖、铁木课桌、门窗五金和黄昏光照已覆盖自由镜头可见全室；加高墙体上沿避免 16:9 镜头露出模型外部。走廊与后三室仍使用 2D 原型。
- 镜头正式采用方案 A：FOV 60°、固定约 21°俯角、3.4 米 SpringArm、1.30 米跟随高度与 0.22 米肩偏的跟随式透视第三人称。鼠标水平移动或手柄右摇杆可连续 360°环绕，垂直观察锁定，不自动跟随角色朝向回正。移动始终按屏幕方向解释，镜头朝向不写存档。
- 当前自由第三人称模式始终保留四面墙，不再执行近墙裁切或淡入淡出；SpringArm 在墙体与家具前缩短镜头距离以避免穿模。旧四方向相机、双墙裁切控制器和着色器只保留作历史实验对照，不由第一室场景加载。
- 第一室不使用悬浮文字。接近目标时显示暖琥珀地面光环；高对比设置显示黑色外圈与白色内圈，操作文本仍由底部提示承载。
- 新游戏使用第一室前部偏右的安全出生点 `(448, 214)`，默认朝向黑板；该点不与家具碰撞、不处于任何初始可用交互点的 1.25 米范围内，并让方案 A 的 SpringArm 完整伸展。已有梦境存档坐标不重置。
- 主角使用 `CharacterBody3D` 和竖直胶囊碰撞；墙、关闭门、教师桌、地图柜及十组课桌椅使用独立 `StaticBody3D`。SpringArm 对墙和家具做体积扫掠，玩家自身从检测中排除。门内交互点可达，但门叶和 `DoorBarrier` 阻止角色走到模型外；交互后锁定输入、开门、淡出并直接切换走廊。旧二维坐标落入障碍物时经 `GameSession` 修正到最近安全点。
- 粉笔、黑板、教师桌和地图柜外观直接由 `DreamEscapeState` 派生，不保存第二份表现状态。主角当前仍用原有 128×192 四向精灵表作为 Fixed-Y `AnimatedSprite3D` billboard；后三室晓雨仍使用 2D 同行位置。
- 第一室保留 `classroom-mvp.blend/glb` 灰盒基线；当前运行时精修版以 `classroom-art-pass-v2.blend` 为权威源，经 Blender MCP 调整、只读临时导出校验后生成 GLB。`classroom-art-pass-v3.blend/glb` 是从 v2 派生、面向暗色原画气氛和近景细节的离线候选，负责人视觉确认前不得替换运行时引用。
- `[计划·v2 静态候选技术检查通过，待视觉确认]` 半写实 3D 主角继续以 Blender 官方 Human Base Meshes v1.4.1 的 CC0 男性人体为离线起点。v1 未绑定技术样模只保留作尺度/导出基线；正式身份锚点、脸发细节板和服装细节板已进入 provenance。原画式 v2 静态 GLB/manifest 已按 `1.69±0.02m` 普通偏瘦体格完成技术导出，并以 `1.7017m`、`34972` 三角面、6 个网格、1 个材质面、无 Armature/Action 的结果通过只读检查；manifest 仍为 `runtimeReady=false`。候选未获负责人视觉确认前，不进行绑定、`idle/walk/jog` 动画或 Godot 接入，当前第一室仍显示 2D billboard。
- 游戏运行和正式构建不依赖 Blender。采用资产、版本、结构参数、哈希、许可证和后处理统一记录在 provenance 与各自 manifest。

## 状态与结算

`DreamEscapeState` 保存当前区域/坐标、物品、已解机关、开放区域、线索、提示等级和晓雨加入状态。状态机预留：

```text
InProgress -> ExitOpened
InProgress -> PinPendingWake -> CompletedPin
预留：EscapePendingWake -> CompletedEscape
```

第一阶段正式产生的终态只有 `ExitOpened` 和 `CompletedPin`。旧 v1 存档没有 `DreamEscape` 字段时按 Legacy 两日切片载入，不提升存档格式版本。
